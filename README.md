# Voice to Text

## Description
A simple AI-based application that converts spoken audio into text using a speech recognition model.

## Technologies Used
- Python
- Streamlit
- Faster-Whisper
- PyAV

## How to Run

1. Activate the virtual environment:
   `voicetotext\Scripts\activate`

2. Install the required packages:
   `python -m pip install -r requirements.txt`

3. Run the application:
   `python -m streamlit run app.py`

## Features
- Accept audio input
- Convert speech into text
- Display the recognized text
